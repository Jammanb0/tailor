# 월간 거래처 매출 정리

## 개요
매달 들어오는 거래처별 매출 엑셀은 담당자·거래처마다 항목 이름이나 열 순서가 조금씩 다르게 옵니다. 이 스킬은 그걸 항상 같은 양식(고정된 항목 이름과 순서)으로 맞춰 정리하고, 그 과정에서 숫자가 안 맞는 곳을 발견하면 그냥 넘기지 않고 반드시 짚어서 알립니다.

## 고정 양식
아래는 이번 스킬에서 항상 지키는 기준 양식입니다. 실제 사용자의 표 항목명·순서가 이와 다르면, 처음 한 번은 아래 항목을 사용자와 함께 확정하고 이 문서에 반영해두세요. 확정된 뒤에는 매달 이 순서를 그대로 씁니다.

1. 거래처명
2. 거래일자 (YYYY-MM-DD)
3. 품목명
4. 수량
5. 단가
6. 공급가액
7. 부가세
8. 합계금액 (공급가액 + 부가세)
9. 비고

> 참고: "공급가액"은 세금을 붙이기 전 물건값, "부가세"는 그 위에 붙는 부가가치세(보통 10%), "합계금액"은 둘을 더한 실제 청구 금액입니다.

## 처리 순서

1. **원본 파일 읽기**
   받은 엑셀(또는 csv) 파일을 열어 실제 열 이름과 순서를 확인합니다.

2. **항목 이름 매칭**
   원본 열 이름을 위 고정 양식의 9개 항목에 대응시킵니다. 이름이 다르게 적혀 있어도(예: "업체명"→거래처명, "날짜"→거래일자, "금액"→합계금액 등) 뜻이 같으면 매칭합니다.
   - 어떤 항목에도 애매하게 매칭되는 열이 있으면, 임의로 짐작해 넘기지 말고 사용자에게 "이 열을 어디에 대응시킬지" 물어봅니다.
   - 고정 양식에 없는 열(예: 담당자 메모 등)은 삭제하지 말고 "비고" 뒤에 별도 열로 붙여둡니다.

3. **순서 재배열**
   매칭이 끝나면 열 순서를 고정 양식의 1~9번 순서로 다시 배열합니다.

4. **숫자 검증 (반드시 수행)**
   아래 세 가지를 항상 확인하고, 하나라도 어긋나면 정리 작업을 멈추지 말고 계속 진행하되, 최종 결과를 넘길 때 어긋난 행을 표로 짚어 함께 보여줍니다.
   - 각 행에서 `공급가액 + 부가세 = 합계금액`이 맞는지 확인
   - 부가세가 공급가액의 10%에서 크게 벗어나는 행이 있는지 확인 (거래처 특성상 다를 수 있으므로 "확인 필요"로만 표시, 자동으로 고치지 않음)
   - 합계금액을 전체 합산한 총액이 원본 파일에 이미 있던 합계행(있다면)과 일치하는지 확인

5. **짚어야 할 것과 그냥 넘어갈 것 구분**
   - **반드시 짚기**: 공급가액+부가세≠합계금액인 행, 수량이나 단가가 비어있는데 합계금액은 채워진 행, 전체 합산액이 원본 합계행과 다른 경우
   - **짚지만 멈추지 않기**: 부가세율이 10%와 다른 행 (거래처마다 면세 등 사정이 있을 수 있음)
   - **조용히 처리해도 되는 것**: 단순 공백 제거, 날짜 형식 통일(YYYY-MM-DD로), 열 순서 재배열

6. **결과 정리해서 보여주기**
   정리된 표를 고정 양식 그대로 보여주고, 그 아래에 "확인이 필요한 항목" 목록을 별도로 정리합니다. 문제가 하나도 없으면 "숫자 이상 없음"이라고 명시적으로 말합니다.

## 확인이 필요한 항목 표시 형식

```
## 확인이 필요한 항목

- N행: 거래처 "OO", 공급가액 100,000 + 부가세 10,000 = 110,000인데 합계금액은 105,000으로 기재됨
- N행: 수량·단가가 비어있는데 합계금액 50,000이 채워져 있음
- 전체 합산액: 계산값 1,234,000 / 원본 합계행 1,200,000 — 34,000원 차이
```

문제가 없을 때:
```
## 확인이 필요한 항목

없음 — 모든 행에서 공급가액+부가세=합계금액 일치, 전체 합산액도 원본과 일치함
```

## 지켜야 할 것
- 숫자가 안 맞을 때 임의로 고쳐서 맞추지 않습니다. 원본 숫자를 그대로 두고 "이상하다"는 사실만 짚습니다.
- 매칭이 애매한 열은 짐작하지 않고 사용자에게 물어봅니다.
- 항목 이름과 순서는 매달 이 문서의 고정 양식을 따릅니다. 거래처 사정으로 양식을 바꿔야 하면, 이 문서를 먼저 업데이트한 뒤 정리 작업을 진행합니다.
