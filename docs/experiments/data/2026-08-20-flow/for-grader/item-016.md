# 거래처별 매출 정리

## 개요
매달 들어오는 거래처별 매출 엑셀을 항상 같은 항목 이름과 순서로 정리한다. 숫자가 안 맞거나 이상해 보이면 조용히 넘기지 않고 반드시 짚어서 확인받는다.

## 정리 기준 (고정)

항목 이름과 순서는 매달 동일하게 유지한다. 아래 순서를 임의로 바꾸거나 이름을 다르게 쓰지 않는다.

1. 거래처명
2. 거래일자
3. 품목/내역
4. 수량
5. 단가
6. 공급가액
7. 부가세
8. 합계금액
9. 비고

> 참고: 원본 파일마다 열 이름이 "업체명", "날짜", "품명" 등으로 제각각일 수 있다. 이런 경우 위 표준 이름으로 매핑해서 바꾸고, 원래 이름이 무엇이었는지는 헷갈리지 않게 기억해둔다(필요하면 매핑 내역을 짧게 메모).

정렬 순서: 거래처명 → 거래일자 순으로 오름차순 정렬한다.

## 작업 순서

1. **원본 파일 확인**
   - 받은 엑셀 파일(들)을 열어 각 시트의 실제 열 구성을 확인한다.
   - 위 9개 표준 항목에 없는 열(예: 담당자, 배송지)이 있으면 삭제하지 말고 사용자에게 "이 항목도 포함할까요?"라고 물어본다.
   - 표준 항목 중 원본에 아예 없는 열이 있으면(예: 부가세가 안 적혀있음) 짚어서 알려주고, 계산해서 채워도 되는지(공급가액의 10% 등) 확인받는다.

2. **항목 이름·순서 통일**
   - 원본의 열 이름을 표준 9개 항목명으로 바꾼다.
   - 순서를 표준 순서대로 재배치한다.
   - 거래처가 여러 파일로 나뉘어 있으면 하나의 표로 합친다.

3. **숫자 검증 — 절대 조용히 넘기지 않는다**

   아래 상황이 하나라도 발견되면, 정리를 계속 진행하되 **반드시 표로 짚어서 사용자에게 보고**한다. 스스로 판단해서 고치거나 그냥 넘어가지 않는다.

   - 공급가액 + 부가세 ≠ 합계금액 (오차가 1원이라도 나면 짚는다)
   - 수량 × 단가 ≠ 공급가액
   - 지난달 같은 거래처 대비 매출이 급격히 튀거나 꺼졌을 때 (예: 3배 이상 차이)
   - 합계금액이 음수이거나 0인 행
   - 거래처명이나 거래일자가 비어있는 행
   - 같은 거래처명이 표기만 다르게 여러 개 존재 (예: "㈜한빛"과 "한빛상사"가 같은 거래처로 보이는 경우)

   짚을 때는 이런 형식으로 정리해서 보여준다:

   ```
   확인이 필요한 항목:
   | 거래처 | 거래일자 | 문제 | 원본 값 |
   |---|---|---|---|
   | 한빛상사 | 03-14 | 공급가액+부가세 ≠ 합계금액 | 공급가액 100,000 / 부가세 10,000 / 합계 105,000 (5,000원 차이) |
   ```

4. **지난달 표와 형태 비교**
   - 지난달 정리 파일이 있으면 열 구성이 이번 달과 같은지 확인한다.
   - 지난달에는 없던 열이 새로 생겼거나, 있던 열이 사라졌으면 먼저 알리고 어떻게 처리할지 물어본다.

5. **최종본 정리**
   - 검증에서 걸린 항목에 대해 사용자의 답을 받은 뒤에만 최종 표를 확정한다.
   - 확정된 표는 표준 9개 항목, 표준 순서, 거래처명·거래일자 오름차순으로 정리해서 내놓는다.

## 하지 말아야 할 것

- 숫자가 안 맞을 때 임의로 반올림하거나 추정해서 채우지 않는다 — 반드시 먼저 물어본다.
- 항목 이름을 그때그때 다르게 쓰지 않는다 (예: 어떤 달은 "합계", 어떤 달은 "합계금액").
- 이상해 보이는 값이라도 "이 정도는 괜찮겠지" 하고 넘어가지 않는다. 사소해 보여도 짚는다.
- 거래처명 표기가 다른 것을 확인 없이 마음대로 하나로 통일하지 않는다 — 같은 거래처인지 먼저 물어본다.

## 마무리 전 점검

- [ ] 항목 이름 9개가 모두 표준 이름과 정확히 일치하는가
- [ ] 정렬 순서(거래처명 → 거래일자)가 지켜졌는가
- [ ] 공급가액/부가세/합계금액이 서로 계산상 맞는지 전부 확인했는가
- [ ] 이상 항목이 있었다면 전부 표로 짚어 사용자 확인을 받았는가
- [ ] 지난달 파일과 열 구성이 같은지 비교했는가
