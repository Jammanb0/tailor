# 거래처별 매출 정리

## 개요
매달 들어오는 거래처별 매출 자료를 **항상 같은 항목 이름·같은 순서**로 정리하고, 숫자가 안 맞아 보이면 조용히 넘기지 않고 반드시 짚고 넘어갑니다.

## 고정 양식 (매번 이 순서·이름을 따른다)

아래는 기본 틀입니다. 실제 회사에서 쓰는 항목 이름이 다르다면 처음 한 번 사용자에게 확인하고, 이후에는 그 이름을 고정값으로 계속 사용하세요.

| 순서 | 항목 이름 | 설명 |
|---|---|---|
| 1 | 거래처명 | 거래처 상호 |
| 2 | 거래일자 | YYYY-MM-DD 형식 |
| 3 | 품목/내역 | 무엇에 대한 매출인지 |
| 4 | 수량 | 숫자만 (단위 표기는 별도 열이나 항목 이름에 포함) |
| 5 | 단가 | 숫자만 |
| 6 | 공급가액 | 수량 × 단가 |
| 7 | 부가세 | 공급가액 × 세율 (세율이 다르면 사용자에게 확인) |
| 8 | 합계금액 | 공급가액 + 부가세 |
| 9 | 비고 | 특이사항 |

정리할 때 지킬 것:
- 원본 엑셀의 항목 이름이 위 표와 다르게 적혀 있어도(예: "업체명" → "거래처명", "날짜" → "거래일자") 위 고정 이름으로 바꿔서 정리합니다.
- 열 순서는 항상 위 표 순서를 따릅니다. 원본 순서가 달라도 재배열합니다.
- 거래처별로 묶어서 정리하고, 거래처 안에서는 거래일자 순으로 정렬합니다.
- 이 표 자체를 바꿔야 할 상황(항목이 새로 필요하다, 이름을 바꾸고 싶다)이 생기면 임의로 바꾸지 말고 먼저 사용자에게 확인한 뒤 이 문서를 함께 수정합니다.

## 작업 순서

1. **원본 파일 확인**
   받은 엑셀을 열어 어떤 항목이 있는지, 몇 개의 시트/거래처가 있는지 파악합니다.

2. **항목 이름·순서 맞추기**
   위 고정 양식에 맞춰 항목 이름을 바꾸고 순서를 재배열합니다. 원본에 없는 항목(예: 부가세가 아예 없는 경우)은 빈 칸으로 두지 말고 어떻게 채울지 사용자에게 묻습니다.

3. **숫자 검산 — 조용히 넘어가지 않는다**
   다음을 하나씩 확인합니다.
   - 공급가액 = 수량 × 단가가 맞는지
   - 부가세 = 공급가액 × 세율이 맞는지 (세율은 보통 10%. 원본에 다른 값이 있으면 그 값을 우선하되 왜 다른지 확인)
   - 합계금액 = 공급가액 + 부가세가 맞는지
   - 거래처별 합계, 전체 합계가 원본 엑셀에 적힌 합계(있다면)와 일치하는지

   **하나라도 안 맞으면**, 계산해서 그럴듯한 값으로 슬쩍 채우거나 넘어가지 말고, 다음 형식으로 반드시 짚어서 보고합니다.

   ```
   [숫자 확인 필요] OO거래처 - OO건
   원본 값: ___
   계산한 값: ___
   차이: ___
   → 원본이 맞는지, 계산이 맞는지 확인해 주세요.
   ```

4. **정리본 산출**
   위 검증을 마친 뒤 고정 양식에 맞춘 표를 만들어 제공합니다. 검산 중 짚어둔 항목이 있다면 정리본과 별도로 "확인 필요 목록"을 함께 제시합니다.

5. **지난달 표와 비교 (지난달 파일이 있는 경우)**
   지난달 정리본이 있으면 항목 이름·순서가 이번 달 정리본과 같은지 확인합니다. 다르면 어느 쪽이 맞는지 묻지 말고, 이번 문서의 고정 양식을 기준으로 통일합니다.

## 완료 전 확인
- [ ] 항목 이름이 고정 양식과 정확히 같은가
- [ ] 열 순서가 고정 양식과 같은가
- [ ] 거래처별 → 날짜순으로 정렬됐는가
- [ ] 공급가액·부가세·합계금액 계산을 전부 검산했는가
- [ ] 숫자가 안 맞는 항목을 빠짐없이 짚어서 보고했는가 (있는 경우)
- [ ] 확인 필요 항목이 있다면 정리본과 분리해서 눈에 띄게 제시했는가
