# 거래처별 매출 정리

## 개요

매달 받는 거래처 매출 엑셀은 담당자나 거래처에 따라 항목 이름과 순서가 조금씩 다르게 들어옵니다. 이 스킬은 원본 데이터를 받아 **항목 이름과 정리 순서를 매달 고정된 형태**로 맞추고, 숫자가 이상해 보이면 그냥 넘어가지 않고 짚어서 확인을 받는 절차입니다.

## 고정 형식 (매달 동일하게 유지)

아래 항목 이름과 순서를 기준으로 삼습니다. 원본 엑셀의 항목명이 다르게 적혀 있어도(예: "업체명"과 "거래처", "매출액"과 "금액") 의미가 같으면 아래 이름으로 통일합니다.

1. 거래처명
2. 거래일자
3. 품목
4. 수량
5. 단가
6. 공급가액
7. 부가세
8. 합계금액
9. 비고

원본에 위 항목 외에 다른 항목이 있으면 임의로 빼지 말고, 맨 뒤에 그대로 붙여두고 사람에게 "이 항목은 기존 형식에 없는데 어떻게 할까요?"라고 물어봅니다. (필요·불필요를 스킬이 스스로 판단하지 않습니다.)

## 작업 순서

### 1단계 — 원본 파일 확인
받은 엑셀 파일을 열어 다음을 확인합니다.
- 시트가 여러 개면 어느 시트가 실제 데이터인지 확인 (헷갈리면 사람에게 물음)
- 헤더(첫 줄 항목명)가 몇 번째 줄에 있는지 확인 — 병합된 셀이나 안내 문구가 위에 붙어 있는 경우가 많습니다.

### 2단계 — 항목 이름 매칭
원본의 각 열을 위 "고정 형식" 9개 항목 중 하나로 대응시킵니다. 대응이 애매한 열(예: "단가"인지 "공급단가"인지 구분이 안 갈 때)은 짐작으로 넘기지 말고 사람에게 확인합니다.

### 3단계 — 정리표 작성
2단계에서 정한 매칭에 따라 항목을 고정 순서대로 재배열합니다. 지난달 정리표와 같은 열 순서, 같은 항목 이름을 유지합니다.

### 4단계 — 숫자 검증 (건너뛰지 않음)
아래 계산이 실제로 맞는지 한 줄씩 확인합니다.

- **공급가액 × 10% = 부가세**인가? (반올림 오차 1원 이내는 허용)
- **공급가액 + 부가세 = 합계금액**인가?
- **단가 × 수량 = 공급가액**인가?
- 합계금액이 음수이거나, 비정상적으로 크거나(예: 자릿수가 하나 더 붙은 것처럼 보이는 경우) 0인 행이 있는가?

어긋나는 행이 하나라도 있으면:
1. 정리표는 일단 만들되, 해당 행을 표시(하이라이트 또는 "확인 필요" 비고)해 둡니다.
2. 어느 행에서, 어떤 계산이, 얼마나 어긋났는지 구체적으로 짚어 사람에게 보고합니다.
   - 예: "12번째 행(㈜한빛상사, 3/15) — 단가 12,000 × 수량 5 = 60,000인데 공급가액이 65,000으로 적혀 있습니다."
3. 사람이 "원본이 맞다" 또는 "고쳐라"라고 답하기 전까지 그 행의 숫자를 임의로 고치지 않습니다.

이 4단계는 절대 생략하지 않습니다. 숫자가 다 맞아 보여도 실제로 계산해서 확인합니다 — 눈으로 훑고 넘어가지 않습니다.

### 5단계 — 최종 확인
정리표를 사람에게 보여주고, 다음을 함께 보고합니다.
- 전체 거래처 수, 전체 합계금액
- 4단계에서 짚었던 행이 있다면 그 목록과 처리 결과(원본 확인/수정함)

## 하지 말아야 할 것

- 항목 이름이나 순서를 스킬 임의로 바꾸지 않습니다 — "고정 형식"이 기준입니다.
- 숫자가 안 맞는데 "대략 맞으니 넘어가자"고 판단하지 않습니다. 아무리 작은 차이라도 짚어서 보고합니다.
- 원본에 없던 항목을 만들어 채워 넣지 않습니다(예: 빈 비고란을 추측으로 채우기).
- 확인 요청 없이 원본 숫자를 수정하지 않습니다.
