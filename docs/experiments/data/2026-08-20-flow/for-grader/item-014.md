# 거래처별 매출 정리

## 개요
매달 들어오는 거래처별 매출 엑셀을 항상 같은 항목·같은 순서로 정리한다. 숫자가 안 맞는 곳(합계 불일치, 빈 값, 이상하게 튀는 값)이 있으면 조용히 고치거나 넘어가지 않고, 반드시 짚어서 사용자에게 확인받는다.

## 고정 형식 (매번 동일하게 적용)

아래는 이번에 정한 기준이다. 사용자가 다르게 지정하지 않는 한 매달 이 형식을 그대로 따른다.

- **항목 이름과 순서**: (예: 거래처명 → 품목 → 수량 → 단가 → 공급가액 → 부가세 → 합계). 실제 항목명·순서는 첫 사용 시 사용자가 확정한 것을 그대로 고정해서 쓴다.
- **정렬 기준**: (예: 거래처명 가나다순, 그 안에서 날짜순). 실제 기준도 첫 사용 시 확정한 것을 고정해서 쓴다.
- **숫자 서식**: 천 단위 구분 쉼표, 소수점 자리수 등도 한 번 정하면 매달 동일하게 유지한다.

> 이 문서를 처음 쓸 때 항목명·순서·정렬 기준이 아직 정해지지 않았다면, 지난달 정리된 표(있다면)를 기준으로 항목명과 순서를 사용자에게 확인받아 이 섹션에 직접 적어 넣는다. 이후부터는 이 섹션이 곧 "고정된 기준"이 된다.

## 작업 순서

1. **원본 엑셀 확인**
   받은 엑셀 파일을 열어 시트 구성, 헤더 위치, 병합된 셀이 있는지 확인한다. 지난달과 헤더 이름이 다르면(예: "매출액"이 "판매금액"으로 바뀜) 무엇이 무엇에 대응하는지 사용자에게 확인한다.

2. **항목 이름·순서 맞추기**
   위 "고정 형식"에 정한 항목명과 순서로 열을 재배치한다. 원본에 없는 항목은 빈칸으로 두고, 원본에만 있고 고정 형식에는 없는 항목은 삭제하지 말고 별도로 표시해 사용자에게 보고한다(빠진 정보일 수 있으므로 마음대로 버리지 않는다).

3. **정렬 적용**
   고정 형식에 정한 정렬 기준(거래처명, 날짜 등)으로 행을 재배열한다.

4. **숫자 검증 — 이 단계는 건너뛰지 않는다**
   아래 항목을 모두 확인하고, 하나라도 어긋나면 표를 완성한 것처럼 넘기지 않고 목록으로 짚어서 보고한다.
   - 합계 행(있다면)이 개별 항목의 합과 실제로 일치하는가
   - 공급가액과 부가세, 합계 사이의 계산이 맞는가 (예: 부가세 = 공급가액의 10%)
   - 빈 값이나 0으로 채워진 셀이 있는가 — 원본에 값이 없어서인지, 계산 과정에서 누락된 것인지
   - 지난달 대비 특정 거래처의 매출이 비정상적으로 튀는가 (몇 배 이상 차이가 나거나, 갑자기 0이 되는 경우)
   - 같은 거래처명이 표기 방식만 다르게 중복되어 있는가 (예: "㈜한빛"과 "한빛(주)")

   어긋난 항목이 있으면 이런 형식으로 보고한다:
   ```
   [확인 필요] ○○상사: 합계가 1,250,000원인데 개별 항목 합은 1,180,000원입니다. 어느 쪽이 맞는지 확인해주세요.
   ```
   임의로 숫자를 고치거나 "대략 맞겠지"라고 판단해 넘기지 않는다.

5. **완성 표 제시**
   숫자 검증까지 마친 뒤 정리된 표를 보여준다. 검증에서 짚은 항목이 있다면 표와 함께 목록으로 같이 전달하고, 사용자의 확인을 받은 뒤 최종본으로 확정한다.

## 완료 전 점검
- [ ] 항목 이름과 순서가 고정 형식과 일치하는가
- [ ] 정렬 기준이 고정 형식과 일치하는가
- [ ] 합계·부가세 등 계산이 실제로 맞는지 확인했는가
- [ ] 빈 값·이상치·중복 거래처명을 확인했는가
- [ ] 확인이 필요한 항목을 임의로 처리하지 않고 목록으로 짚었는가
