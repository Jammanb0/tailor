# 3차 확장 — 판정선 사전 등록

> **생성 전에 작성했다.** 1차·2차 모두 "다음부터는 먼저 적겠다"고 써놓고 지키지
> 않았다. 이 문서는 자료를 보기 전에 쓴 것이며, 이후 수정하지 않는다.
> 작성 시각: 2026-08-19, 코퍼스 커밋 `0d31446` 직후 · 생성 실행 전.

## 이번에 바꾼 것

**`voice` 카테고리만 채웠다.** 패턴 4개 → 19개. 렌더 61,273 → 75,025바이트
(+13,752). 나머지 8개 카테고리와 구조 골격은 **바이트 단위로 동일함을 확인**했다
(28개 렌더 섹션 중 27개 무변화).

`documentation`은 이번 회차에서 **제외했다.** 원 소스 `doc-coauthoring`의 라이선스가
확인되지 않기 때문이다 — `anthropics/skills`에는 루트 라이선스가 없고, 스킬 폴더마다
개별 `LICENSE.txt`를 두는데 18개 폴더에는 있고 `doc-coauthoring`에는 없다. GitHub
API의 `license` 필드도 `null`이다. 정책 A(MIT/Apache만)를 만족한다고 볼 근거가
없어 채우지 않았다. `explanation`은 감사할 원문이 없어(Tailor 자체 제작) 제외했다.

따라서 **3차 회차의 계획표는 "voice + documentation + explanation"이었으나 실제
독립변수는 `voice` 단독**이다.

## 주 지표와 판정선

**주 지표는 E축(내적 일관성)이다.** 2차에서 처음으로 ±0.33을 넘는 부작용이 났고
(3.77 → 3.27), 갈래 선택 (가)(그대로 진행하며 관찰)을 고른 근거가 "하락폭이 아직
작고 C·A축은 멀쩡하다"였기 때문이다. 그 근거가 유지되는지를 이번에 본다.

| 판정 | 조건 |
|---|---|
| **확장 성공** | `voice` 시나리오의 F축(절차 무결성)이 2차 대비 **+0.33 이상** 상승 |
| **부작용 없음** | 안 건드린 9개 시나리오의 F축이 전부 **±0.33 이내** |
| **E축 안전장치 통과** | 전체 E축 평균이 2차 대비 **-0.33보다 덜 하락** |

**E축이 -0.33 이하로 또 내려가면, 갈래 (다)(카테고리 선별 주입)를 앞당기는 것을
정식 안건으로 개시한다.** 이번 회차에서 결론을 내지는 않되, "관찰만 계속한다"는
현재 방침은 그 시점에 폐기한다.

## 미리 적어두는 예측과 그 근거

- **voice F축은 오른다.** 1차(code-review 1.67 → 3.00)와 2차(테스트 +1.00,
  디버깅 +0.67)에서 채운 카테고리마다 F축이 올랐다. 세 번째 반복이다.
- **voice B축(용어 해소도)도 오를 가능성이 있다.** 이번에 넣은 값들이 대부분
  성격 서술을 동반한다(선택지 7개·채널 6종 전부 `character` 필드 포함). 다만
  design에서 확인된 반례가 있으므로 강한 예측은 아니다.
- **E축은 또 내려갈 수 있다.** 2차에서 관찰된 기제(앞머리 요약 절이 본문을 같은
  명령형으로 되풀이)를 이번에도 고치지 않았다. 분량은 오히려 더 늘었다.

**반복하지 않을 예측**: 2차에서 "분량 때문에 사용자 상황이 묻힌다"고 예측했다가
빗나갔다(C축이 한 칸도 안 움직였다). 같은 예측을 다시 세우지 않는다.

## 자료 취급 규칙

- **성공 건수를 먼저 확인한 뒤에 수치를 낸다.** 과거 한도 소진으로 30건 중 8건만
  성공한 자료로 수치를 낸 사고가 있었다. 실행기가 실패 건수를 경고로 찍는다.
- **점수가 움직이면 해당 문서를 직접 연다.** 수치만 보고 원인을 판정하지 않는다.
  1차·2차 모두 이 자리에서 오진했다.
- **채점은 블라인드로 한다.** 코퍼스를 채운 쪽이 채점하지 않는다. 2차 30건과 섞어
  60건으로 만들고, 조건 라벨을 지우고, 어느 구간을 잘라도 두 조건이 반반이 되게
  배치한다(`make-blind.mjs`).
- **B·E축의 절대값을 과거 문서와 섞어 쓰지 않는다.** 두 축의 앵커가 정정됐으므로
  직전 조건 30건을 함께 다시 채점해 조건 간 비교만 성립시킨다.

## 이번 회차에서 손대지 않기로 한 것

대조군이 깨지므로 **전 카테고리 렌더를 바꾸는 변경은 전부 미룬다.**

- 소스 그룹핑 렌더(`sourceIds`가 프롬프트에 안 실리는 문제)
- `verification-before-completion`의 baseline 승격
- "요약 절 금지" 규칙 추가 — 2차 E축 하락의 관찰된 기제를 직접 겨냥하지만 (나) 갈래다
- 금지 섹션 제목의 이중부정 사고(2차 `item-037`)
- **프롬프트의 `대상은 완전 초심자입니다` 문장**(`prompt.ts`) — 2026-08-18
  포지셔닝 정정("초심자 전용이 아니다")과 어긋난 채로 남아 있다. 3차 준비 중
  발견했다. 채점 B축은 그때 고쳤는데 이 문장은 안 고쳐졌다
